# I am Sorry (static site)
Open index.html, or deploy the folder: Netlify Drop (drag the folder to app.netlify.com/drop) or GitHub Pages (push, then Settings > Pages > main / root).
Real stickers: put PNGs in assets/ named catheart, pig, blanket, flowers, cake, momos, bike, plead, bunny, bunnyflower, cry, monkey, sign (.png). They replace the built-in drawings automatically.
Letter photo: add assets/photo.png.
